Hospital Management System
Overview

This project creates a simple Hospital Management Database using MySQL. It stores patient information, symptoms, patient details, prescriptions, and room occupancy.

Database

Database Name: hospital_management

Tables
patients – Stores patient ID and name.
symptoms – Records symptoms such as fever, cough, and rashes.
patient_details – Stores email, Aadhaar number, phone number, and age.
prescriptions – Stores medicines and supplements prescribed to patients.
rooms_occupancy – Tracks the availability and reserved rooms.
Key Features
Primary and foreign keys
UNIQUE and NOT NULL constraints
Relationships between patient-related tables
Default value for reserved rooms
Sample patient, symptom, prescription, and room data
SELECT queries to display all records
How to Run
Open MySQL Workbench or any MySQL client.
Copy and execute the SQL script.
The hospital_management database and required tables will be created.
Sample data will be inserted and displayed using the SELECT queries.
